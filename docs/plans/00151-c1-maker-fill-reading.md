**Interfaces:**
- Produces, all in `cli/panel/fills.py`:
  - `GRID_S = 15`; `HORIZON_S = 900`; `CANCEL_AFTER_S = 5`; `STALE_S = 30`; `SIZE_RUNGS = (0, 1)`; `MID_OFFSETS_S = (60, 900, 3600)`; `COLUMNS` the eighteen names of the Global Constraints in order.
  - `@dataclass class Order`: `ts: datetime`, `pair: str`, `side: str`, `size: int`, `price: Decimal`, `our_qty: float`, `queue_ahead_qty: float`, `queue_ahead_notional: float`, `mid_at_post: float`, `spread_at_post_bps: float`, `stale_seconds_at_post: float | None`, `filled_qty: float = 0.0`, `away_since: datetime | None = None`, `filled_at: datetime | None = None`, `cancelled_at: datetime | None = None`, `mids: dict[str, float] = field(default_factory=dict)` — the mids read so far, keyed by their column names; `is_open`, a property, `filled_at is None and cancelled_at is None` — the one open test `apply_trade`, `tick_cancel` and `simulate_hour` read; in the order's row `time_to_fill_s` is `filled_at − ts` and `cancelled_s` is `cancelled_at − ts`, in seconds, each null where the order never filled or was never cancelled, and `fill_price` is `float(price)` when filled.
  - `post_orders(book: OrderBook, ts: datetime, pair: str, *, stale_seconds: float | None) -> list[Order]` — the four orders (two sides × two rungs) at the best bid and ask; `[]` when either side is empty (a one-sided book has no mid, so neither side posts); `our_qty` = `notionals_for(quote)[rung] / float(price)`, `queue_ahead_qty` the level's quantity as a float, `queue_ahead_notional` = `queue_ahead_qty × float(price)` in the pair's quote — the unit `notionals_for(quote)` states the sizes in, BTC for `ETH/BTC` and `SOL/BTC`; `mid_at_post` = `(bid + ask) / 2` and `spread_at_post_bps` = `(ask − bid) / mid × 1e4` over the best bid and ask as floats, `sample_row`'s `mid` and `spread_bps`; the stale test is `simulate_hour`'s, taken before the call.
  - `apply_trade(order: Order, trade: dict) -> None` — a trade `{"ts", "side", "price", "qty"}` as the trades frame's row holds it, `price` a Float64 that `apply_trade` compares as `Decimal(str(price))`, the conversion `cli/capture/book.py::_to_decimal` makes of a level's price — the one place a print's price becomes `Decimal`, so every caller passes the frame's rows unchanged: a `sell` at `price <= order.price` on an open `bid` order, a `buy` at `price >= order.price` on an open `ask` order, adds `qty` to `filled_qty`; when `filled_qty >= queue_ahead_qty + our_qty` the order fills at `order.price` with `filled_at = trade["ts"]`; any other trade, and any trade on an order not `is_open`, changes nothing.
  - `tick_cancel(order: Order, book: OrderBook, ts: datetime, tick: Decimal) -> None` — on an order `is_open`: the best quote on its own side read from `book` — `max(book.bids)` for a bid, `min(book.asks)` for an ask — away when that side is empty or `best != order.price and abs(best - order.price) >= tick`, compared as `Decimal`; `away_since` set on the first away second, cleared when back; `cancelled_at = ts` when `ts − away_since >= CANCEL_AFTER_S` seconds (a level moved at second s0 cancels at s0 + 5, the sixth away second) or `ts − order.ts >= HORIZON_S` seconds.
  - `pair_tick(book: OrderBook) -> Decimal` — the smallest positive `Decimal` gap between consecutive levels on either side, the tick's proxy, taken at each grid second and held until the next; `Decimal(0)` when neither side holds two levels, and with tick 0 any move is away.
  - `simulate_hour(messages: list[dict], trades: list[dict], book: OrderBook, hour: datetime, *, pair: str, carried: list[Order], last_msg_ts: datetime | None) -> tuple[list[dict], list[Order], OrderBook, datetime | None, dict]` — `messages` the book hour's `regroup_messages`, `trades` the trades hour's rows sorted by `ts`, their prices the frame's Float64; the panel's second loop: at each second boundary of `[hour, hour + 3599 s]` apply the messages up to it, then the trades up to it against every open order (`apply_trade`), then `tick_cancel` every open order, then read each carried order's pending mids whose instant — `fill + 60 s`, `fill + 900 s`, `post + 900 s`, `post + 3600 s` — is at or before the boundary (the book's mid at the first boundary at or after the instant whose book has both sides), and turn into a row every order whose `post + 3600 s` mid is read, the last of its instants (a fill comes by `post + 900 s`, so `fill + 900 s` is by `post + 1800 s`); then on a grid second (`second % GRID_S == 0`) the staleness as `materialize_hour` takes it — above `STALE_S` the four orders are skipped, `skipped_stale += 4` — else `post_orders`, `[]` counting `skipped_no_quote += 4` and four orders `posts += 4`; the messages and trades after the last boundary are applied after the loop, as `materialize_hour` drains its messages; returns `(rows, carried, book, last_msg_ts, counts)` — `carried` every open order and every closed one whose `post + 3600 s` mid is unread, `counts = {"posts", "skipped_no_quote", "skipped_stale"}` in orders.
  - `flush(carried: list[Order]) -> list[dict]` — the one place a pending mid becomes null: every carried order as a row, its unread mids null, an order still open a censored post (`filled` false, `time_to_fill_s`, `cancelled_s` and `fill_price` null); the producer calls it where the data ends (Task 2).
  - `rows_frame(rows: list[dict]) -> pl.DataFrame` — the `COLUMNS` schema, sorted by `ts`, `side`, `size`.
