## Review Focus

1. The boundary bars — a return whose first bar is stamped 2026-07-09 20:00 is not in the slice, the one whose first bar is 2026-07-10 00:00 is; a return whose second bar is stamped 2026-03-31 20:00 is in the reference, the next is not. Pinned in Task 1's `test_the_slice_starts_at_the_first_return_whose_first_bar_is_on_or_after_its_start` and `test_the_reference_ends_at_the_last_return_whose_second_bar_is_on_or_before_its_end`.
2. A return inside the spent holdout window enters neither the slice, the band nor the in-sample prefix. Pinned in Task 1's `test_no_return_inside_the_holdout_window_enters_a_metric`.
3. The band's last window — a window ending exactly at the reference's end is counted, none past it. Pinned in Task 1's `test_the_band_counts_every_window_that_fits_and_none_past_the_end`.
4. The legs' equality edges — a slice Sharpe equal to the 5th percentile passes leg 1, a drawdown equal to the 95th percentile passes leg 2. Pinned in Task 1's `test_a_leg_at_its_band_edge_passes`.
5. The instrument check's edges — a prefix one return short, or a Sharpe 0.00006 off, gives no verdict; a Sharpe 0.00004 off gives one. Pinned in Task 1's `test_the_instrument_check_gives_no_verdict_off_record_47`.

  - `revalidation_metrics(governed: list[float], ungoverned: list[float], bench: list[float], h4_ts: list[datetime], *, n_trials: int) -> dict` — first the slice `[lo, hi)` from `slice_bounds(h4_ts, SLICE_START)` and `slice_returns = hi - lo`, a `RevalidationError` naming the count when `slice_returns < MIN_SLICE`, before any band or Sharpe is computed; then exactly `METRIC_KEYS`, every value a builtin `int` or `float`: `in_sample_returns` = `prefix_end(h4_ts, REFERENCE_LAST_BAR)`, `in_sample_sharpe` of `governed[:in_sample_returns]`; the reference `governed[DECISIVE_START:in_sample_returns]`, its length `reference_returns`; the band over the reference at `length = slice_returns`, `step = BAND_STEP`, held as `ref_band` — never `band`, whose assignment would make the function's own call to `band()` raise `UnboundLocalError`; `band_windows = len(ref_band.sharpes)`; `slice_sharpe`, `slice_maxdd` of `governed[lo:hi]`; `slice_sharpe_rank` = `sum(s <= slice_sharpe for s in ref_band.sharpes) / band_windows`, the share of `ref_band.sharpes` at or below `slice_sharpe`; `slice_sharpe_ungoverned` of `ungoverned[lo:hi]`; `slice_bench4h_sharpe` = `0.0 if not any(bench[lo:hi]) else sharpe(bench[lo:hi], periods_per_year=PPY_4H)`, spec D6's flat slice decided before the call, never by catching `sharpe`'s `ValidationError`; `slice_mean_diff_vs_bench4h` = mean of `governed[lo:hi]` less mean of `bench[lo:hi]`; `slice_dsr` = `deflated_sharpe_ratio(sharpe(governed[lo:hi]), slice_returns, n_trials=n_trials, var_trials=P1_VAR_TRIALS)`, its counts by keyword; `leg_sharpe_pass`, `leg_maxdd_pass` = `legs(slice_sharpe, slice_maxdd, ref_band)`. `in_sample_sharpe`, `slice_sharpe`, `slice_sharpe_ungoverned`, `slice_bench4h_sharpe` and the band's Sharpes are annualized, `sharpe(..., periods_per_year=PPY_4H)`; `slice_dsr` alone reads the per-period Sharpe. The three series are taken as `len(h4_ts) - 1` returns each, the shape `_crossfreq_book` and `benchmark_4h_net_of_cost` return, and no length is checked.
