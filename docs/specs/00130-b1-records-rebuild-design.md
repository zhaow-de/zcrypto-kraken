- A build's compute error — `AlphaError` (the substrate-extent check, spec 00045 F8, included), `BacktestError`, `BenchmarkError`, `FeatureError`, `ValidationError` — is a `SubjectError` naming the subject and its window, as `_b2_build` names B2's.
