```python
    if m["head_to_head_mean_outperf_2021"] > 0 and m["max_drawdown_reduction_pct"] > 1e-6:
        return "adopt" if m["head_to_head_spa_p_2021"] < 0.05 else "park"
    return "reject"
```

The third instrument finding, the block and the counts against this basis, is not a metric and stays a pre-flight step (D7).
