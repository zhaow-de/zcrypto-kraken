[iter-008 · instrument check] Base-vs-quarterly OHLCVT merge policy — found on the real archive by the smoke test.
The base dump and the 2023–2025 quarterly updates OVERLAP and DISAGREE on volume/trades (OHLC matches): the base
carries HIGHER volume + trade counts (more complete — it is the latest full export downloaded today; the quarterlies
were generated at each quarter and are staler). Example XBTEUR 2023-04-01 01:27: OHLC identical, base vol=0.09917354/7
trades vs quarterly vol=0.06707112/6. The naive "merge all + raise on same-ts conflict" aborts the whole run.
  1. **Base authoritative for its range; quarterlies extend only beyond it.** Use the base dump for 2013→2025-12-31
     (its full, more-complete range) and quarterly rows ONLY for ts > the base's last ts (Q1-2026 is exactly contiguous
     at 2026-01-01 00:00, no overlap). Uses the better data + eliminates conflicts. (Decision: 1)
  2. Merge all + prefer base on conflict + count — more general, but the extra machinery buys nothing (the in-range
     quarterlies are uniformly staler, not gap-fillers).
  (Decision: 1). Interior base gaps (if any) are a QA finding, not backfilled from staler quarterlies. The synthetic-zip
  unit tests could not surface this — the loop's instrument-check smoke test on the real archive did.

[iter-011] Phase 1 — empty-interval reconstruction (deferred follow-up). (Decision: 1)
The full-history dataset has 7807 no-trade gaps (no trades in an interval → no bar). "Reconstruction" = fill them.
  1. **A tested `fill_gaps` transform utility (opt-in, on-read)** — insert one synthetic bar per missing grid point:
     OHLC = prior close (flat), vwap = prior close, volume = 0, count = 0. Reusable; a backtest applies it IF it needs
     contiguous bars, so the fabricated data is explicit + opt-in, NOT baked into the canonical dataset.
  2. Bake a gap-filled dataset variant — ready contiguous data, but a synthetic zero-volume flat bar looks like a real
     bar and can bias features; it also fabricates data into a stored canonical.
  (Decision: 1) — the utility, not a baked dataset ("the data is what it is" + distrust-the-instrument); a filled
  variant stays generatable on-demand from the utility if a strategy needs it.
