## Note on the retroactive close-out (and the fix)

Phase 0's §12 artifacts are a *set* (ratification sheet + snapshot register + adapter memo) with **no single "close-out report"** — so the decisions-drain trigger, which keys on a phase's close-out report, never fired at the Phase 0 → 1 boundary, and the phase's decisions sat un-drained while Phase 1 proceeded. This report retroactively supplies that trigger. The convention is hardened in the same change (`.claude/rules/decisions-log.md`, `.claude/skills/research-loop/SKILL.md`): a phase whose §12 artifacts name no single close-out report still gets a **short dedicated phase-boundary report** that triggers the drain, and no phase's iterations begin until the prior phase is closed out.
