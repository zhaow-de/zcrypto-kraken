# Agent operations

- **Never guess a path on a fleet host** — read `docs/reference/fleet.md` (pins in `fleet-pins.md`) and the data catalogs first; probe only where the doc is silent, and write what the probe finds back into the doc in the same change.
- **A recorded footgun names the safe alternative in the same sentence** — "don't use the default X" without "use Y at Z" strands the next context at the moment it needs the answer.
- **Before requesting the user's word on an irreversible/production action, sweep the open-topics index + memo for blockers** and present the result with the request — "ready" without the sweep is not ready.
- **Verification is scoped to what the change can reach, and reach is grepped, not reasoned** — `git grep -l <path> -- tests/` plus whatever globs the file's directory; a meta-test that walks `tests/test_*.py` is reached by a file's EXISTENCE, so adding or renaming a file is its own blast radius. The full suite is CI's and the data-gated families are not (CLAUDE.md); a workflow triggered on `push`, not `pull_request`, is outside PR CI — run its build locally before merging what it consumes; a docs-only diff still reaches `tests/test_internal_terms_not_operator_visible.py`. Name what each check would catch before running it, and the files run and the selection rule after: a green is evidence only about what it exercised, and a clean commit gate is a formatter pass, never a passing suite.
- **A guard (assert, alert rule, CI check, test) is unproven until the defect it names is constructed and seen to trip it** — on a fixture where defect and correct behaviour DIFFER (a degenerate fixture passes under the defect and proves nothing), reading WHICH failure fired (a red exit can be the guard misfiring on a healthy path), with a **true-positive** beside it — a healthy, production-shaped input that must pass, or an always-refusing guard ships green. Assert the SELECTION before the loop and print its count. A test double answers the MODE — a stub identical in every mode the code distinguishes is degenerate for every mode defect — and an injection default is a live call site, not a seam: require the keyword. A property of a FILE is pinned by content (a verbatim region and its sha256), never by an enumeration of forbidden spellings; read any canonicalisation adversarially — every line it drops is a line the pin cannot see.
- **Assert on what the defect moves, not on the headline** — exit codes, published aggregates and `$?` after a pipeline (the last command's status, not the probe's) are identical on both sides of most real defects.
- **Timeout-guard every network-touching command** (`git push/pull/fetch/ls-remote`, every `gh` call): prefix `timeout 20`–`60`, and run it as its own small step — never buried in a long compound command. For CI waits, poll with per-call timeouts instead of one long foreground wait.
- **Never spawn a shell that polls/waits for a background job you started** — the harness re-invokes you when it completes; a genuine wait on external state goes *inside* the one backgrounded command doing the work.
- **`pgrep -f` / `pkill -f <pattern>` match their own command line** — bracket one character (`pgrep -f "[p]attern"`) or the guard never goes false / the kill hits itself. This shell is zsh: an unquoted `$var` is one word, never a split command — spell a probe command out or pass an array; and `$var:` followed by a letter is a history modifier, not a colon — quote `"$rev:path"`.
- **Subagent dispatch prompts say: plain blocking commands, background nothing, do not end the turn before the commit exists** — and still expect to resume: a subagent whose final message says it is *waiting* is stranded with the work uncommitted — check `git status`, then resume the **same** agent via SendMessage with numbered foreground steps ending at the commit, never a fresh twin; a "failed: API error" notification can be premature — check the tree first.
- **Never run two subagents that may write the same worktree concurrently.** Dispatch write-capable agents one at a time, or give each `isolation: "worktree"`. Read-only reviewers may run in parallel with each other, but not alongside a writer — and a reviewer permitted to mutate-and-restore is a writer.
- **Mutation probes run through `infra/scripts/mutate-probe.sh`, never a hand-rolled mutate-and-restore loop** — its header states its refusals. `--collect-only` first: a `-k` filter can deselect the test under proof, and a control that does not bite may be selection, not the guard. A dirty tree it rightly refuses, and a reviewer that must mutate, both get a detached `git worktree` at the commit — the reviewer dispatched write-capable, never a hand-rolled loop inside a read-only brief.
- **A probe outside the repo tree must PROVE which tree it imported** — assert `cli.__file__` starts with the intended root before trusting any verdict. A copied `.venv` keeps its shebang on the original interpreter (inside a copy, `./.venv/bin/python -m pytest`, never `uv run pytest`); `python script.py` puts the SCRIPT's directory in `sys.path[0]` while a relative WRITE resolves against cwd — a scratch script's outputs are absolute paths.
- **`git mv` stages a rename of the INDEX version** — edits made before the move stay unstaged and `git status` shows `R100`; `git add` the new path after every `git mv`, and verify an invariant against the **committed** tree, never the working tree.
- **Chain history-rewriting git commands one per call, never compounded** — verify each step's EFFECT (HEAD moved, subject matches, tree equal) before issuing the next, never its exit code; `--amend` folds the staged set into HEAD, so read `git log -1 --stat` first — hooks see the staged set, never the mixture the amend produces.
- **A grep hit is not a call site** — open the match and confirm it before claiming X calls Y; a docstring, comment or string literal justifies nothing about runtime reachability.
- **A number in prose is first asked whether it is needed at all** — an enumeration carries no count beside it ("the following points", never "the following three points"). A number that stays names the set it quantifies and the command that measured it, in the same sentence: never arithmetic over totals that may not nest, never the tree before the change when the change's tree is the claim, never a reviewer's or subagent's figure before you reproduce it at full precision, and never a relay of an unreproduced figure into a dispatch, memo or report — the relay is the laundering step.
- **Never write a digest or hash from memory** — read it from its source and verify shape and existence (64 hex, present in a commit) before recording it: an invented value in a rollback record looks usable and is not.
- **Attribute an observed mutation only after proving the suspect command's MODE could produce it** — fingerprint first (an ansible `--check` renders against controller-local temp; a real write stages into the remote user's temp); a timing coincidence is never an attribution.
- **Python `str.replace` edits silently no-op on a missed match** — `assert old in s` (or verify the output) every time; a batched edit script that raises has applied a prefix — re-run it whole from a clean tree, never patch forward from the line that raised.
- **Snapshot unversioned data before any tool rewrites it** — gitignored files have no undo, so copy them aside first and delete the copy only after the final verification that could read it.
- **Correct a durable doc by rewriting the narrative in place, never by appending retraction bullets** — the uncorrected story reads first, and more confidently than the correction below it; the file must read correctly cold.
- **Retiring or restructuring a durable doc first sweeps the removed text for live deferred actions** (owed checks, "no earlier than", pending verifications) — a deferral whose only home is prose dies with the prose; register, discharge, or explicitly drop each in the same change.
- **A completion signal can belong to a different run** — a finished oneshot retains the previous run's `Result`, `is-active` exits 3 while `activating`, and a `Persistent=true` timer's catch-up tick answers right after a manual run: anchor every green to your own run's timestamps and reconcile the arithmetic against the work you dispatched.
- **Widen and prove a guarding test BEFORE the migration it guards** — a test still pointed at the old layout goes green against a file the content has left; land the widened guard first and see it bite on both layouts.
- **Two producers measuring the same thing independently are the check on each other** — when they disagree, the disagreement IS the finding; a single source cannot report that it is under-reporting.
- **Rule out your own changes explicitly, with timestamps** — compare an alert's `activeAt` against every converge, restart and drill of that day before attributing it to anything else; the deploy is the cheapest wrong answer available.
- **An empty filtered query is not an absent event** — require a positive trace, validate the filter before trusting its emptiness (`infra/scripts/ops-postverify.sh` embodies this for ops converges), and print the input's line count before trusting any zero: a bare `docker logs --since HH:MM:SS` fails to parse and greps clean; unprivileged `journalctl -u` on a system unit prints `-- No entries --` under a hint to rerun with `sudo`. A flat counter is *pending*, never *clean*, until the pipeline's booking opportunity for that window has passed (`infra/runbooks/drills-telemetry.md` states the reconciler's tick). **Alert timing comes from the source system** — the rule's `activeAt`, or `GET /api/v1/rules/history` with `from`/`to` in epoch SECONDS as `infra/scripts/ops_daily.py` calls it — never a Slack delivery stamp, which bounds delivery and nothing earlier; an empty history page is a unit or window error before it is an absence. A filter over machine output claims that output's grammar: print the line that PRECEDES each match, cross-check the recap's own count, and classify a terminal state positively (`status == COMPLETED`), never as the absence of pending words.
- **Time-gated reminders go to Slack `#zcrypto`** (`slack_search_channels` finds it) — never fall back to a DM, and a scheduled message cannot be deleted via API, so schedule it right the first time.
- **Never narrate a wall-clock time or elapsed duration you did not just measure** — `date -u` at the TOP of the command that writes the stamp, never at its end; a peer message's or owner instruction's time is the transcript's own timestamp.
- **Host-touching (ssh/sudo) steps run in the main loop, never inside a dispatched subagent or workflow** — the permission gate blocks them there and the step dies where nobody sees the prompt; gather host evidence first, or expect the rejection and re-dispatch from the main loop.
- **A repo script failing on a missing host binary is a host finding to report, not a script to patch** — and what the probe found goes into `fleet.md` in the same change.
- **Observed drift is not license** — a recent change that skipped a required step is a finding to flag, never a template to copy.
- **A local branch is not a merge path until its remote/upstream is verified** — `git ls-remote --heads origin <branch>` plus the upstream ref; no remote and an upstream pointing elsewhere = a local composition that merges nowhere.
- **Sweep for the CLAIM, not the phrase you wrote** — enumerate its variants before grepping, re-sweep after each fix round, and name the point-in-time records deliberately left carrying the old wording.
- **A truncated sweep is not a sweep** — piping aggregated evidence through `head`/`tail` before the assertion silently drops the counterexample; bound the input per-file, never the evidence stream.
- **Append to `.local/agent-lessons/<your session>.jsonl` the moment it happens** — in the main checkout, never a worktree's (removed after merge): *it was mine* / *I mistakenly* / *the third time* / *a miscount: a count typed beside data that says otherwise*; a rule you decided not to follow (which, and why); feedback on a rule or skill. One JSON line in the shape `infra/scripts/check-agent-lessons.py` enforces, your own file, never a committed ledger — the refine round harvests every inbox in its own PR; never at closeout from memory.
- **A cause that fits is not a cause that was checked** — before reporting one, name the cheapest check that would refute it and run it. The live shapes: an explanation adopted because it fits, with the refuting read one command away; a PATTERN substituted for the NAMED field; a claim about a state the reporter structurally cannot see (a payload session can say *I have heard nothing*, never *the owner has not spoken* — only the coordinator can tell those apart); an anchor verified unique but not for what ENCLOSES it.
- **Announcing a step is not taking it** — "sending X" / "next: Y" followed by an ended turn — and it hits the coordinator too, which nothing pokes. At the top of every turn, read your own last declared next step against what actually happened, before anything else.
- **Never say a job, review, or subagent is running unless you dispatched it in this turn and hold its result line** — otherwise the words are *not started* or *unknown*. The coordinator's hourly poke resumes a stalled turn; this is the standard it enforces.
- **Re-open the authority at the moment of use** — the spec, the memo chain, the approval text — never a stored summary of it: the summary is usually right and incomplete. The moment of use is BEFORE the step it governs, and it includes a rule you are about to cite as a reason: quote its clause and its scope line, never its gist.
- **`grep`/`rg` here honour `.gitignore`** — a whole-tree sweep silently misses everything under `.local/` (the memo, the coordination table, the inboxes); `grep` (ugrep here) needs `--no-ignore-files`, `rg` needs `--no-ignore` (`rg --no-ignore-files` still hides it) — or name the file.
